# EventHorizon API

A RESTful backend API for an event management platform. The API handles user registration, email verification, authentication, and protected user profile access.

## Live API
https://techyjaunt-assignment.onrender.com

The deployed API will be added here after deployment.

## Features

- User registration
- Joi validation
- Password hashing with bcrypt
- Email verification
- JWT authentication
- Protected user profile route
- MongoDB with Mongoose
- Error handling
- Environment variables for sensitive credentials
